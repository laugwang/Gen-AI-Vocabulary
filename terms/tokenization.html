斷詞與 Token

Tokenization

入門

一句話定義

Tokenization 是把一段文字切成一個個「token」（字、詞或詞的片段），並轉成整數編號，讓模型能處理文字。

白話比喻

就像把一篇文章剪成拼圖片，每一片都有自己的編號。模型不讀「字」，只讀這些編號；常見的詞是一整片，罕見的詞會被拆成好幾片。

運作原理

  1. 準備一份詞彙表（vocabulary），通常有數萬到十幾萬個 token。
  2. 用 BPE 等演算法，把文字盡量切成詞彙表裡最長的片段。
  3. 每個片段查表換成一個整數 ID，例如 "Hello" → 9906。
  4. 模型輸出時也是一次吐出一個 token ID，再查表轉回文字。

小例子

同一句話，中文和英文切出來的 token 數量常常不同，這也是 API 計費、上下文長度限制都以 token 計算的原因。

"I love AI"   → ["I", " love", " AI"]          # 3 個 token
"我喜歡人工智慧" → ["我", "喜歡", "人工", "智慧"]   # 依詞彙表而定

常見誤解

  • 誤解：一個 token 就是一個字。 其實：token 可能是一個字、一個詞，或半個英文單字，取決於詞彙表。
  • 誤解：token 越少越好。 其實：詞彙表太大會讓模型變大、罕見 token 學不好，是一種取捨。
