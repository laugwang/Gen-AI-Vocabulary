注意力機制

Attention / Self-Attention

進階

一句話定義

Attention 讓模型處理每個 token 時，算出它和其他 token 的關聯程度，再依權重匯集資訊。

白話比喻

讀到「他把蘋果放進冰箱，因為它快壞了」裡的「它」時，你會自動回頭看「蘋果」。注意力機制就是讓模型學會這種「回頭看重點」的能力。

運作原理

  1. 每個 token 的向量被轉成三份：Query（我在找什麼）、Key（我有什麼）、Value（我的內容）。
  2. 用 Query 和所有 Key 做內積，得到關聯分數。
  3. 分數經過 softmax 變成加總為 1 的權重。
  4. 用這些權重把所有 Value 加權平均，得到新的、融合上下文的表示。
  5. Transformer 會同時做很多組（multi-head），各自關注不同關係。

小例子

論文《Attention Is All You Need》中的核心公式：

Attention(Q, K, V) = softmax( Q·Kᵀ / √d ) · V

常見誤解

  • 誤解：注意力權重就是模型「真正的理由」。 其實：權重可以幫助觀察，但不等於完整的決策解釋。
  • 誤解：Attention 只在文字模型裡出現。 其實：Stable Diffusion 的 U-Net 也用 cross-attention 讓文字提示影響圖像。
