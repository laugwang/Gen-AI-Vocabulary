嵌入向量

Embedding

入門

一句話定義

Embedding 是把文字、圖片等資料轉成一串固定長度的數字（向量），讓「意思相近」變成「距離相近」。

白話比喻

想像一張超大的地圖：「貓」和「狗」被放在附近，「貓」和「冰箱」離得很遠。Embedding 就是每個詞在這張地圖上的座標，只是這張地圖有幾百甚至上千個維度。

運作原理

  1. 每個 token ID 先查表得到一個向量（這張表是訓練學出來的）。
  2. 模型層層運算後，可以得到整句話、整段文章的向量。
  3. 用餘弦相似度（cosine similarity）比較兩個向量有多接近。
  4. 相似度高 → 意思相近，可用於搜尋、分群、推薦。

小例子

經典的例子是向量的加減法能保留語意關係：

vec("國王") - vec("男人") + vec("女人") ≈ vec("女王")

常見誤解

  • 誤解：每個維度都代表一個人看得懂的意義。 其實：大多數維度是混在一起的特徵，單看一個維度通常沒有明確意義。
  • 誤解：Embedding 只能用在文字。 其實：圖片、聲音、商品都可以有 embedding，CLIP 甚至把圖和文放在同一個空間。
