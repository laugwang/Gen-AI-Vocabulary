擴散模型

Diffusion Model

進階

一句話定義

Diffusion Model 先學習如何從加了雜訊的圖片中把雜訊去掉，生成時再從純雜訊出發，一步步去噪得到新圖片。

白話比喻

像是看著一張被雪花雜訊蓋住的電視畫面，每次只擦掉一點點雜訊。擦了幾十次之後，畫面就清楚了，而且是一張新畫面。

運作原理

  1. 訓練時：把真實圖片逐步加上高斯雜訊，直到變成純雜訊（前向過程）。
  2. 訓練一個神經網路（常用 U-Net），讓它看著有雜訊的圖，預測加了什麼雜訊。
  3. 生成時：從隨機雜訊開始，反覆用網路預測並減去雜訊（反向過程），通常 20–50 步。
  4. 加入文字條件（text embedding + cross-attention），就能「依照描述」生成圖片。
  5. Stable Diffusion 在壓縮後的潛在空間（latent）中做擴散，以節省運算。

小例子

一個典型的文字生成圖片設定：

prompt: "a cozy cafe on a rainy night, watercolor"
steps: 30        # 去噪次數
cfg_scale: 7     # 多聽 prompt 的程度
seed: 42         # 固定起始雜訊 → 可重現

常見誤解

  • 誤解：模型是把資料庫裡的圖片拼貼起來。 其實：模型學的是去噪的規律，生成時從隨機雜訊開始計算出新圖。
  • 誤解：步數越多圖一定越好。 其實：超過一定步數後品質幾乎不再提升，只會變慢。
